# Project Guidelines

## Git Commit Messages
- **Short & Humanized**: Keep commit messages concise, simple, and natural (e.g., "clean up gpu memory after long songs", "add hall reverb controls to vocal studio").
- **No Prefixes**: Never use conventional prefixes like `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `feat(...)`, `fix(...)`, etc.
- **Direct**: Briefly state what was changed in plain English.
